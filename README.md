# YTGrab Smart Discovery // Stark Industries // HARRY⚡

> An advanced, lightning-fast YouTube media acquisition, smart search, and deduplication web application built with Python, `yt-dlp`, and FFmpeg. Featuring a futuristic Stark Industries / J.A.R.V.I.S. glassmorphism UI.

---

## 🚀 Features

* **🔍 Smart Movie & Artist Discovery:** Search directly for movies, artists, moods, or playlists without needing raw URLs upfront.
* **🧹 Automatic Deduplication:** Intelligently filters out duplicate uploads, low-quality rips, 8D audio, and shorts to serve up clean, high-quality official tracks.
* **🎬 High-Quality Video & Audio Downloads:** Automatically merges separate video/audio streams into a single, seamless file using FFmpeg (Supports MKV, MP4, WebM, MP3, M4A, Opus, FLAC, WAV).
* **🌐 Multi-Language Audio Support:** Language-aware audio selector with automatic fallback to default tracks (Tamil, English, Hindi, Telugu, Malayalam, etc.).
* **🛡️ Built-In Safety & Extras:** SponsorBlock integration, chapter/metadata embedding, cover art thumbnail embedding, subtitle support, and speed limiters.
* **🛸 Futuristic J.A.R.V.I.S. Interface:** Sleek responsive liquid glass design complete with live download queues, theme switchers (Arc, Mark III, Ultron), throughput monitoring, and optional voice feedback.

---

## 🛠️ Prerequisites

Before running the application, ensure you have the following installed on your system:
1. **Python 3.8+**
2. **FFmpeg** (Required for merging video/audio streams and audio conversion)
   * *Windows (via winget):* `winget install ffmpeg`
   * *Mac (via Homebrew):* `brew install ffmpeg`
